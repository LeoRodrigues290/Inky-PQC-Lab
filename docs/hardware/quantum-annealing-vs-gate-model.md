# Recozimento Quântico (Quantum Annealing) vs Modelo de Circuitos

Comparativo entre as duas principais abordagens de computação quântica:

| Aspecto | Quantum Annealing (D-Wave) | Gate-Based Model (IBM, Google, IonQ) |
|---|---|---|
| **Paradigma** | Adiabático / Minimização energética de Ising | Portas lógicas quânticas universais |
| **Universalidade** | Não universal (específico para QUBO/Ising) | Universal (qualquer circuito quântico) |
| **Escala de Qubits** | 5.000+ qubits com menor coerência | Centenas a milhares com alta coerência |
| **Aplicações** | Otimização combinatória, amostragem | Criptografia, simulação química, algoritmos universais |
