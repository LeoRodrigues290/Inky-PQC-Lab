# Computação Quântica Cega (Blind Quantum Computing)

Permite que um cliente com recursos quânticos mínimos terceirize um cálculo para uma nuvem quântica não confiável sem revelar suas instruções ou dados.

## Propriedades
- O servidor executa o circuito quântico completo.
- O servidor não consegue aprender:
  - O algoritmo que está sendo executado.
  - A entrada do cálculo.
  - O resultado final obtido.
