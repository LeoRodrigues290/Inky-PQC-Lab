# Códigos de Superfície (Surface Codes)

O código de superfície é a arquitetura líder para computação quântica tolerante a falhas (FTQC) devido ao seu alto limiar de erro.

## Métricas Principais
- **Limiar de Erro:** $\approx 1\%$ sob ruído despolarizante local.
- **Topologia:** Conectividade 2D em grade de vizinhos mais próximos.
- **Operadores de Síndrome:**
  - Plaquettes estreladas ($X$-checks): $S_s = \prod_{i \in v} X_i$
  - Plaquettes de face ($Z$-checks): $S_p = \prod_{j \in p} Z_j$
