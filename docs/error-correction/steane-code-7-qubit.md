# Código de Steane [[7, 1, 3]] (CSS Code)

Proposto por Andrew Steane em 1996, baseado no código clássico de Hamming $[7, 4, 3]$.

## Notação [[n, k, d]]
- $n = 7$: 7 qubits físicos.
- $k = 1$: 1 qubit lógico protegido.
- $d = 3$: distância de código, detecta até 2 erros e corrige 1 erro arbitrário.

## Portas Transversais
O código de Steane possui o conjunto transversal de Clifford completo: portas $H$, $S$ e $CNOT$ lógicas podem ser aplicadas bit a bit sem propagação descontrolada de erros.
